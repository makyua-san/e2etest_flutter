# 03. 日付: 新しい順（降順）の検証

共通前提は `README.md` を参照してください。

## 目的

正常系のもっとも重要な期待値として、利用明細一覧が `日付: 新しい順（降順）` で表示されることを確認します。

## 事前条件

- アプリが起動している
- ログイン画面またはログイン済み画面から開始できる
- この手順書単体で開始し、他シナリオの実施結果を前提にしない

## 端末操作

- なし

## 画面操作

1. 未ログインの場合は `demo_user` / `password` でログインする
2. ホーム画面、設定画面、または明細詳細画面にいる場合は、画面下部の `取引` タブをタップして利用明細一覧を開く
3. 一覧の先頭行の `timestampISO` を確認する
4. 一覧の2行目の `timestampISO` を確認する
5. 必要に応じて対象行の `tx.row.<id>.timestamp` セマンティクスを使って値を記録する

## 期待結果

- 1件目の `timestampISO` が2件目より新しい
- ソートラベルが `日付: 新しい順` のままである
- 逆順になっていない

## 判定例

- 合格例
  - 1件目: `2026-01-29T10:00:00Z`
  - 2件目: `2026-01-18T10:30:00Z`
- 不合格例
  - 1件目の日時が2件目より古い

## 証跡メモ

- このシナリオの開始画面
- 一覧の先頭2件が読めるスクリーンショット
- 比較した `timestampISO` の記録
