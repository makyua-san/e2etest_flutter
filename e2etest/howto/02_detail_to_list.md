# 02. 明細詳細 -> 取引一覧へ遷移

共通前提は `README.md` を参照してください。

## 目的

明細詳細画面から、ボタンまたはボトムタブ経由で利用明細一覧へ正しく遷移できることを確認します。

## 事前条件

- アプリが起動している
- ログイン画面またはログイン済み画面から開始できる
- この手順書単体で開始し、他シナリオの実施結果を前提にしない

## 端末操作

- なし

## 画面操作

1. 未ログインの場合は `demo_user` / `password` でログインする
2. ホーム画面にいる場合は `取引を確認する` から利用明細一覧を開き、任意の明細をタップして明細詳細画面へ移動する
3. 設定画面にいる場合は、画面下部の `取引` タブをタップして利用明細一覧を開き、任意の明細をタップして明細詳細画面へ移動する
4. すでに利用明細一覧を表示している場合は、任意の明細をタップして明細詳細画面へ移動する
5. 明細詳細画面で `取引一覧を見る` をタップする
6. ボタンが使えない場合は、画面下部の `取引` タブをタップする

## 期待結果

- 利用明細一覧が表示される
- 一覧件数が表示される
- ソートラベルが `日付: 新しい順` である
- 各行に `merchant` `amount` `timestampISO` `status` が表示される
- ボトムタブバーが引き続き表示される

## 証跡メモ

- このシナリオの開始画面
- 明細詳細画面で操作する直前の画面
- 一覧画面へ遷移した直後の画面
