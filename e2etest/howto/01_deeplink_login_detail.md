# 01. ディープリンク -> ログイン -> 明細確認

共通前提は `README.md` を参照してください。

## 目的

ディープリンクで指定した明細へ遷移しようとしたとき、未ログイン状態ではログインを挟み、認証後にホームではなく対象の明細詳細へ直接到達できることを確認します。

## 事前条件

- アプリが起動している
- ログイン前の状態である
- 対象明細は `tx_0006` である

## 端末操作

### 端末B

1. アプリが起動していることを確認する
2. 次のコマンドでディープリンクを実行する
   - `adb shell am start -a android.intent.action.VIEW -d "e2etestflutter:///transactions/tx_0006"`

## 画面操作

1. ログイン画面で Username に `demo_user` を入力する
2. Password に `password` を入力する
3. `Login` ボタンを押下する

## 期待結果

- ログイン後にホーム画面を経由せず、明細詳細画面へ直接遷移する
- 明細詳細画面に `tx_0006` の情報が表示される
- `merchant` が Amazon である
- `amount` が空でない
- `timestamp` が表示される
- `status` が表示される
- 画面下部にボトムタブバーが表示される
- `取引一覧を見る` ボタンが表示される

## 証跡メモ

- ディープリンク実行直後の画面
- ログイン完了後の明細詳細画面
