# 正常系E2E テスト管理

`e2etest/howto/README.md` は、正常系E2Eシナリオの親ファイルです。
ユーザーはこのファイルを更新してシナリオ一覧と結果を管理し、AIはこの一覧に合わせて個別手順書を作成・更新します。

## 運用ルール

- シナリオの追加・改名・並び替えは、このファイルのチェックリストを更新して行う
- AIは、このファイルに載っているシナリオだけを `e2etest/howto/` 配下の個別手順書に同期する
- チェックボックスは `合格` を表す。未実施または未合格のシナリオは未チェックのまま残す
- 不合格や保留は、末尾の `結果メモ` に記録する
- 共通前提や共通データはこのファイルを参照し、個別手順書にはシナリオ固有の操作を書く

## 共通前提

- テストユーザー: `demo_user` / `password`
- Seedデータ: 利用明細は11件、合計 `39,390 JPY`
- 正常時の期待値: 一覧のソート順は `日付: 新しい順（降順）`
- ディープリンク: `e2etestflutter:///transactions/tx_0006`
- adbコマンド: `adb shell am start -a android.intent.action.VIEW -d "e2etestflutter:///transactions/tx_0006"`

## チェックリストの更新方法

新しいテスト項目を追加したい場合は、上のチェックリストに1行追加してください。
AIはこの一覧を正として、不足している個別手順書を `e2etest/howto/` 配下に作成します。

### 追加時の書式

```md
- [ ] `07` シナリオ名 (`07_file_name.md`)
```

### 記入ルール

- 番号は連番にする
- シナリオ名は人が読んで分かる日本語にする
- ファイル名は番号付きのスネークケース風にそろえる
- 追加だけでなく、改名や並び替えもこのチェックリストを更新して表現する

### 追加例

```md
- [ ] `07` ログアウト後に未認証状態では明細詳細へ戻れないことを確認 (`07_logout_route_guard.md`)
- [ ] `08` 金額マスクON時に一覧と詳細の両方で金額が隠れることを確認 (`08_mask_amount_visibility.md`)
```

### AIへの依頼例

```text
e2etest/howto/README.md を更新しました。
チェックリストを正として、追加された項目に対応する手順書を e2etest/howto/ 配下へ作成してください。
既存ファイルは親ファイルの一覧に合わせて同期してください。
```

## 初期セットアップ

1. このリポジトリのルートディレクトリへ移動する
   - 例: `cd e2etest_flutter`
2. 端末Aでアプリを起動する
   - `flutter run`
3. 端末Bで接続デバイスを確認する
   - `adb devices`
4. ログイン画面が表示されていることを確認する
5. 必要に応じて初回スクリーンショットを取得し、表示と座標ずれがないことを確認する

## 合格基準

- ディープリンク後のログイン完了時に、指定した明細詳細へ直接遷移する
- ボトムタブでホーム・取引・設定を移動できる
- 明細一覧が表示され、先頭2件が降順になっている
- 一覧から開いた詳細の値が一致する
- 設定が再ログイン後も保持される

## 結果メモ

- `FAIL` や `BLOCKED` があればここに記録する
- 例: `03`: FAIL - 先頭が `tx_0000` で昇順になっていた
